# Mid-Day Meal Scheme & Primary Education in Tamil Nadu
## Research Question
What is the relationship between Mid-Day Meal Scheme budget allocation and elementary gross enrolment in Tamil Nadu?
## Data
- Period: 2003–04 to 2024–25
- Observations: 22
- Dependent variable: Elementary Gross Enrolment Ratio (GER)
- Independent variable: Mid-Day Meal Scheme budget allocation
## Methodology
- Time-series analysis
- Ordinary Least Squares (OLS) regression
- Log-log specification
- Microsoft Excel Data Analysis ToolPak
## Key Finding
The estimated coefficient on Mid-Day Meal Scheme budget allocation was -0.0828 and statistically significant at the 5% level (p = 0.0066).
The result indicates a statistically significant negative association between the variables in the sample, rather than establishing a causal effect.
## Limitations
The analysis uses national-level budget allocation as a proxy because consistent state-level expenditure data was unavailable. Elementary GER was also used as a proxy because consistent Tamil Nadu dropout data was unavailable.
The study also recognises potential omitted-variable bias.
